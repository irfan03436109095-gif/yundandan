Mac 同时连 Wi-Fi 和网线，机场走哪边？先查网络服务顺序

淡定点2026-11-20— 次阅读
网络体验

Mac 插着网线，Wi-Fi 也保持连接，不能仅凭插线动作就说所有机场流量已经改走有线。先看系统采用的网络服务顺序，再确认客户端使用系统代理、应用内代理还是 VPN/TUN 等方式接管。两层分别核对，才不会把接入变化误当节点变化。

服务顺序决定的是哪一层

Apple 说明，多种网络服务同时活跃时，Mac 会按列表顺序尝试连接；可以在网络设置中调整服务顺序。VPN 连接的优先级另有规则，不能像普通服务一样随意重排。Apple 网络服务顺序说明。

这个设置不能直接证明某个应用实际采用哪条代理路由，也不代表两条接入带宽自动相加。当前连接、应用行为与客户端接管方式仍需分别验证。

示意图：接入服务的优先顺序与代理接管属于不同层；图不承诺自动叠加带宽或无缝切换。

改动前先留下可恢复的信息

记录当前网络服务名称、连接状态与原顺序，以及客户端选择的节点和接管方式。不要在远程协助、会议或传输途中试验断开接入。受单位管理的网络遵守其管理要求，不自行删除服务或描述文件。

如果经常需要在家与办公环境采用不同条件，可了解 macOS 的网络位置来保存不同设置；它不是今天必须新增的步骤。Apple 网络位置说明。

查看顺序后，用两轮小任务检查

  1. 打开“系统设置 → 网络”，查看 Wi-Fi 与以太网是否确实连接，区分已连接和只是列在服务中。
  2. 在操作菜单中查找“设定服务顺序”并记录原列表。菜单名称与位置按当前系统界面为准。
  3. 仅在允许的环境调整一次顺序，保持客户端、节点与目标任务不变，完成一个小页面请求。
  4. 如仍无法确认接入，可在不中断重要任务的条件下暂时停用其中一种接入再复测，并记录操作。
  5. 按需要恢复原连接与顺序，重新完成原任务。

查看顺序是线索；“切到单一接入后原任务怎样变化”才是一份可比较的观察。已有连接可能需要应用重新发起请求，因此不要只看一个一直未重载的页面。

系统代理要进入对应服务核对

若使用 macOS 系统代理，Apple 的设置流程是先选网络服务，再进入代理选项。Apple 代理设置说明。Wi-Fi 的配置正确，不能替以太网配置作确认。应用内代理和其他接管方式则按客户端正式说明检查。

检查层 记录内容
接入 当前启用的服务、原顺序、单接入对照
代理 接管方式、实际入口、节点与相关连接记录
任务 同一页面能否打开、错误文字与时间

公网出口 IP 相同不一定证明接入没有变化，因为两种接入可能最终走同一代理出口；出口不同也不能单独说明哪种接入更快。若比较性能，需要固定任务、顺序和采样条件，另外记录。

怎样算排查结束

能够说清本次测试启用了什么接入、调整了哪一项、原任务是否恢复，并把不再需要的临时改动恢复。机场推荐的多端或多网络体验，应记录真实接入条件，不能仅写“Mac 能用”。

  • Apple：更改代理设置
