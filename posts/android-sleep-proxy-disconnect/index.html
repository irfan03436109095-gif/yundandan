安卓锁屏后机场断开？先排查省电与后台限制

安卓手机亮屏时代理正常，锁屏一段时间后消息延迟或网页需要重新连接，不能立刻判断节点不稳定。Android 的 Doze 与 App Standby 会在设备闲置时限制后台 CPU 和网络活动，不同品牌还可能提供额外的省电管理。

调整省电设置会增加耗电，应该先用对照确认，再只修改当前机场客户端相关项。

建立可复现步骤

  1. 选择一个已知可用节点，记录客户端连接时间。
  2. 亮屏访问固定网页，确认当前出口与连接正常。
  3. 锁屏并保持设备静置 10 至 20 分钟。
  4. 解锁后立即检查客户端状态、通知、日志和固定网页。
  5. 在充电与不充电状态各做一次，观察问题是否只在闲置省电时出现。

Android 官方说明，Doze 会在设备未充电、静置且屏幕关闭一段时间后推迟后台网络和 CPU 活动，并在维护窗口短暂恢复。设备被唤醒、移动或接上充电器后会退出 Doze。

再检查应用电池设置

进入 设置 → 应用 → 目标客户端 → 电池，记录当前是优化、受限还是不受限。不同品牌名称和路径可能不同，不要照搬截图。先把“受限”改为系统默认的“优化”做对照；只有问题稳定复现且该客户端确需持续运行时，才短期测试“不受限”。

同时检查：

  • 客户端是否有持续连接或前台服务通知；
  • 系统省电模式是否开启；
  • 厂商后台清理是否把客户端移除；
  • 锁屏后 Wi-Fi 是否切换到蜂窝网络；
  • 订阅或节点本身是否在亮屏状态也会断开。

不要一次改完所有设置

一次只改一个项目，再按相同锁屏时长复测。若设为不受限后仍断开，应恢复原设置，继续检查网络切换、客户端日志和节点。若只在某一节点发生，也要做换节点对照。

验收标准

通过标准包括：锁屏后客户端仍保持预期连接；解锁后固定网页无需手动重启即可访问；电量消耗处于自己可接受范围；恢复默认设置后能明确复现差异。这样才能把系统后台限制与机场节点问题分开。

来源：Android Developers：Doze 与 App Standby、Google Pixel 电池优化说明。
